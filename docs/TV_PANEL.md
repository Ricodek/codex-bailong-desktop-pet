# 电视面板定制源码

此 Fork 在上游 1.2.1 源码基础上增加供电视远距离使用的桌宠面板，本地定制程序版本为 1.3.2。此仓库提供源码，没有发布与该版本对应的安装包；上游的下载入口仍指向上游版本。

- 面板可自由拖动，靠近屏幕四边后收纳；在收纳位置附近悬停可展开，也可以固定面板。
- 面板密度支持 100% 和 110%，正文大小可单独调整，并可选择减少动态效果。
- Token 用量统一使用中文数量单位，数字与单位的字重、间距及垂直位置经过调整。
- 修复人物出现后遮挡面板、导致部分按钮无法点击的情况；不改变人物的比例或动画素材。
- 程序与人物素材分开管理。素材不包含在源码或本次提交中，需在设置中按需下载。

此定制构建以 Windows 和独立工作区布局为目标：源码位于工作区的 `开发/source`，程序、数据和素材分别位于同一工作区的 `程序`、`数据` 和 `素材`。`BAILONG_HOME` 可指定工作区根目录。使用 Python 3.12 安装 `requirements-enhanced.txt` 后，可运行 `tools/build_portable.py` 在工作区内生成本地程序构建；构建本身不会发布安装包。

Token 和会话数据来自本机已配置的数据源；不要将账户凭据、会话、运行日志、构建缓存或用户下载的素材提交到仓库。原项目与第三方组件的来源及授权边界见 [NOTICE](../NOTICE.md)。
